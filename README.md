# 触心 (TouchSoul) - 银发族专属 AI 陪伴管家

触心 (TouchSoul) 是一款专为老年人设计的“零UI”人工智能陪伴应用。它抛弃了传统复杂的菜单和按钮，通过最符合直觉的四种手势，结合 DeepSeek 大模型，为长辈提供情感慰藉、健康管理和生活辅助。

## 核心交互设计与调研依据 (为什么选择这四个手势？)

在适老化设计调研中，我们发现传统的“点击图标-进入层级-寻找功能”模式是老年人数字鸿沟的主要来源。因此，触心采用了“Zero-UI”理念，将所有高频需求映射到四个最基础的肌肉记忆手势上：

1. **单指轻触 (Tap) -> 每日简报与播报**
   * **调研依据**：轻触是智能手机最基础的交互。老年人常有“不知道看什么”的迷茫感。轻触屏幕任何位置即可获取当天的日期、天气、新闻和健康建议，属于“被动接收信息”的最佳方式，零认知负担。
2. **长按说话 (Long Press) -> 语音对话**
   * **调研依据**：微信语音的“按住说话”是老年群体普及率最高、最熟悉的交互方式。我们复用了这一肌肉记忆，长按即可与 AI 进行自然语言交流，松手即发送，避免了复杂的语音唤醒词或打字输入。
3. **左右滑动 (Swipe) -> 场景模式切换**
   * **调研依据**：滑动符合物理世界的“翻页”直觉。老年人不需要理解复杂的“设置”菜单，只需滑动即可在“热闹模式”（适合白天解闷）、“安静模式”（适合午后闲聊）和“守护模式”（适合深夜助眠）之间无缝切换，UI 颜色和 AI 性格会随之改变。
4. **双击屏幕 (Double Tap) -> 紧急呼叫**
   * **调研依据**：在紧急或恐慌状态下，精细的点击操作极易出错。双击屏幕任意位置作为一种“重度、急促”的物理反馈，能有效防止误触，同时在真正需要时能最快触发紧急联系人拨号。

## 商业潜力与社会价值

* **降低获客与客服成本**：极简的交互大幅降低了学习门槛，减少了子女的“教学成本”和企业的客服压力。
* **精准切入银发经济**：随着老龄化加剧，针对老年人的情感陪伴和健康监测是巨大的蓝海市场。触心不仅是工具，更是“数字伴侣”。
* **Multi-Agent 架构扩展性**：底层采用多智能体协同（意图识别 -> 分发给健康/情感 Agent -> 自动调用工具），未来可轻松接入医疗问诊、社区服务、电商购物等商业化 API。

## 技术架构 (Multi-Agent 协同)

触心不仅是一个单体对话机器人，其内部实现了 **Multi-Agent 协同与自主决策 (Function Calling)**：

1. **意图分类 (Intent Classification)**：用户说话后，轻量级模型会先判断意图是“求助/健康”还是“聊天/倾诉”。
2. **Agent 分发**：根据意图，请求会被路由给【专业健康与生活助手 Agent】或【情感慰藉与陪伴 Agent】，从而表现出不同的专业度和语气。
3. **自主工具调用 (Function Calling)**：AI 拥有自主决策权，不仅是被动回答，还能主动调用工具。例如：
   * 感应到用户情绪低落时，主动调用 `switch_mode` 切换到热闹模式。
   * 听到用户说“明天去医院”，主动调用 `add_personal_memo` 记录备忘录。
   * 听到用户身体极度不适，主动调用 `contact_family_emergency` 触发告警。

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. 在项目根目录创建 `.env` 文件，设置 `DEEPSEEK_API_KEY=你的DeepSeek密钥`（可在 https://platform.deepseek.com 获取）
3. Run the app:
   `npm run dev`
